# CareConnect Command

An interactive strategy platform for our UEC case competition proposal: making Canada the trusted destination for post-weight-loss body contouring through three linked policies.

**Connect → Expand → Reinvest**

1. **Canada CareConnect** (0–12 months): trusted provider certification, one patient-services platform, and a recovery network. Toronto pilot.
2. **Healthcare Capacity Accelerator** (years 1–5): conditional incentives for proven new capacity and international talent recruitment.
3. **Canada Health Dividend** (years 2–5): a proposed 5% contribution on international procedure revenue, reinvested in Canadian healthcare.

## Modules

- **Strategy overview**: the problem, the three policies, why Canada and why now.
- **Network map**: clickable Canadian hubs with readiness scores, a pilot gate, and actions for each policy (certify clinics, add capacity, simulate a complication).
- **Policy simulator**: five-year model of patients, revenue, the Health Dividend, and the effect on Canadian patients, with presets and charts.
- **Stakeholder impact**: who gains and who worries under each policy, at three intensities.
- **Patient planner**: what an international patient sees — itinerary, provider standards and all-in cost.
- **AI strategy advisor** and **judge critique**: work when the page is opened inside Claude; every other module works anywhere.
- **Evidence**: cited figures and every modelling assumption.

## Run it

It is one static file. Open `index.html` in a browser, or publish with GitHub Pages:
**Settings → Pages → Build and deployment → Deploy from a branch → `main` / root → Save.**
